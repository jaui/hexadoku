# Puzzle designed by a reader, S. Jobse - not by Claude Ghyselen and not
# by Gery Szcepanski, which makes it the odd one out of the whole series.
# The rules are stated in full on the page: "De Alfadoku werkt met alle
# letters van het alfabet, met uitzondering van de Z, dus A t/m Y." A
# 25x25 grid in which every letter A-Y appears once in each row, each
# column and each 5x5 box. No digits, no extra rule - the plainest of the
# three wide layouts, and unusual only in its alphabet.
#
# The grid is printed across the double page, but not halved evenly: 16
# columns on the left page and 9 on the right.
#
# It is the hardest puzzle in this archive by a wide margin. Where the
# AlphaSudoku falls to propagation alone and the Alphanumski takes one
# branch, this one needs about 450000 branch nodes - and that is what the
# readers ran into. Elektuur printed their letters in 10/2006: one had
# given up after weeks and suspected several solutions, another had
# written a program that solves sudokus and hexadokus but "blijft hangen
# omdat het geen eenduidige oplossing kan vinden". The editors hedged:
#
#   We sluiten dat niet helemaal uit; bij zo'n grote puzzel bestaat
#   inderdaad de kans dat er meer dan een oplossingsmogelijkheid is en
#   een computerprogramma kan daar behoorlijk op vastlopen. ... Daarom
#   rekenen we maar een oplossing goed en dat is: IDRFBV.
#
# The hedge was unnecessary. The solution is unique, and the six red
# answer cells give exactly the code they announced. The programs of 2006
# did not hang on ambiguity but on difficulty.
#
